# rs-public-toolbox

A collection of assorted public tools — small, self-contained utilities that run entirely in the browser without any backend, login, or installation required.

## Available tools

| Tool | Description |
|------|-------------|
| [Package Identifier Tool](https://1337-rene-schmidt.github.io/rs-public-toolbox/package-identifier/) | Generate and validate pharmaceutical package identifiers: PZN, NTIN, GTIN, PPN, and PCID. |
